01 — Method

Built to be audited, not trusted.

The pipeline makes the quiet work visible: search logs, evidence quotes, credibility bands, contradictions, and the gaps you would rather hide.

01

Evidence ledger

Every claim carries a verbatim quote and a locator; every source carries a SHA-256 snapshot of what was actually read.

02

Citation verification

DOI and citation resolution, online and offline. Fabricated references and number drift never make it into the report.

03

Contradiction protocol

Conflicts are recorded, graded and adjudicated, with severity and resolution kept on the record.

04

Requirement coverage

Every prompt requirement is mapped to an anchor that appears in the report, or waived with a stated reason.

05

PRISMA-lite search log

Every query is journaled with an ID, engine, hit count and screening outcome. Reproducible by default.

06

Bilingual reports

Persian and English reports with real RTL, light and dark themes, embedded fonts, and clean A4 print output.

02 — Pipeline

Ten phases. Every exit is a gate.

Each phase produces artifacts the next phase can check. Nothing advances on vibes.

  1. 00

    Intake

    Question, profile, deliverable type and explicit requirements.

    Gate brief + requirements
  2. 01

    Landscape

    Angles, actors and a source map before any query runs.

    Gate angles covered
  3. 02

    Plan

    Initial queries, collection matrix and stop rules.

    Gate query plan
  4. 03

    Collect

    Route queries to free public APIs; snapshot every source.

    Gate search log
  5. 04

    Extract

    Verbatim quotes with locators, never paraphrase as evidence.

    Gate quotes validate
  6. 05

    Assess

    Credibility bands, source tiers and screening reasons.

    Gate credibility scored
  7. 06

    Verify

    Citations, numbers, modality, corroboration and staleness.

    Gate claims verified
  8. 07

    Synthesize

    Findings, contradictions and explicit gaps.

    Gate findings cited
  9. 08

    Report

    Markdown and self-contained HTML; hard report gates.

    Gate 12 hard checks
  10. 09

    Retrospect

    What worked, what failed, and reversible learning proposals.

    Gate governed learning

06 — FAQ

Questions worth asking.

Does it need API keys?

No. Twelve free public search APIs, web fetch and PDF extraction work without keys. Optional keys only add capacity; the pipeline is designed to run keyless.

Which agents does it support?

Claude Code, OpenCode, Codex, Cursor and any generic skill directory. The installer auto-detects platforms; SKILL.md carries the workflow.

What does one run produce?

A brief and plan, a search journal, source snapshots, an evidence ledger, a verification report, findings, report.md, a self-contained report.html and a retrospective.

Is the Persian output real RTL?

Yes. Reports are rendered in English or Persian (auto-detected or --lang fa), with RTL layout, embedded Vazirmatn, translated labels and APA 7 references.

What do the hard gates check?

IDs resolve, every fact line is cited, numbers match sources, no placeholders, open contradictions stay visible, weak claims are labeled, requirements are covered and bibliography fields are complete.
